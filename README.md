# Smartline : 더 편한 지하철 이용을 위한 서비스
- `2024-2학기 공학설계입문`
- `2024-2학기 공학설계입문 작품전시회 장려상`
- `Java`
</br>

## 문제 정의 및 문제 분석
### 1. 실시간 혼잡도
지하철을 이용하기 전까지 지하철의 혼잡도를 알기 어렵다. 많은 사람들이 사용하는 지하철과 관련된 어플리케이션에서 현재 지하철의 혼잡도를 알 수 있는 기능이 없으므로 SK Open API를 이용하여 현재 혼잡도를 알 수 있는 기능을 추가하였다.
### 2. 지하철 커뮤니티
갑작스러운 지하철 사고나 여러 이유로 인한 지연 등을 지하철과 관련된 어플리케이션 상에서 알기 어렵다. 열차 지연 정보를 보다 빠르게 알 수 있도록 지하철 커뮤니티를 만들어서 이 커뮤니티를 통해 지하철 사용자들이 서로 정보를 공유할 수 있도록 하였다.  
</br>  


## 기능 
### 1. 실시간 혼잡도
SK OPEN API에서 제공하는 혼잡도를 ５가지로 분류하여 제공
(쾌적／여유／보통/혼잡／매우 혼잡）

### 2. 지하철 커뮤니티
수도권 1~9호선 메뉴 탭, 회원가입/로그인/로그아웃 기능
